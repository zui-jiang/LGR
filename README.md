# LGR: Lookahead Group Reward

[![arXiv](https://img.shields.io/badge/arXiv-2605.30833-b31b1b.svg)](https://arxiv.org/abs/2605.30833)
[![NeurIPS 2026](https://img.shields.io/badge/NeurIPS-2026-6846a5.svg)](https://neurips.cc/Conferences/2026)

Research code for **[Your Teacher Can't Help You Here: Combating Supervision Fidelity Decay in On-Policy Distillation](https://arxiv.org/abs/2605.30833)**.

Yanjiang Liu, Jie Lou, Xinyan Guan, Yuqiu Ji, Hongyu Lin, Ben He, Xianpei Han, Le Sun, Xing Yu, and Yaojie Lu.

LGR helps a student preserve useful teacher supervision during long reasoning trajectories. It scores candidate tokens by the teacher's confidence **one step ahead**, then uses their relative scores as a training reward.

[Getting started](docs/reproduction.md) · [Implementation guide](docs/implementation.md) · [Contributing](CONTRIBUTING.md)

## Why look one step ahead?

In on-policy distillation (OPD), the teacher scores prefixes generated by the student. As these prefixes grow, teacher supervision can become less confident and less discriminative: **Supervision Fidelity Decay (SFD)**. LGR compares the teacher's next-token confidence after different student candidate tokens, favoring choices that preserve future supervision quality.

1. Generate a student trajectory and identify positions with high student entropy.
2. Select the student's top-K candidate tokens at each selected position.
3. Score the candidates with a tree-attention teacher forward pass, splitting requests when needed.
4. Normalize candidate confidence within each group and optimize it alongside the distillation objective.

For candidate `v` at position `t`, the raw reward is `max_w p_teacher(w | prefix, v)`. The paper's group reward subtracts the candidate-group mean and divides by its standard deviation. Tree branches share the original prefix and cannot attend to other branches.

## Results reported in the paper

Mean@8 averaged across AIME-24/25/26, HMMT-25/26, and LiveCodeBench v6 (Table 1):

| Student | OPD (9k) | LGR | Gain |
| --- | ---: | ---: | ---: |
| DeepSeek-R1-Distill-Qwen-1.5B | 31.57 | 33.18 | +1.61 |
| DeepSeek-R1-Distill-Qwen-7B | 45.78 | 48.35 | +2.57 |

The 1.5B setting uses Skywork-OR1-Math-7B for math and DeepCoder-14B for code; the 7B setting uses DeepSeek-R1-Distill-Qwen-32B. Results are from Table 1 of the paper.

## What is included?

- A modified **Slime** training stack with OPD losses and lookahead confidence collection.
- A modified **SGLang** serving stack with `parent_ids` tree scoring and parent-indexed log probabilities.
- The **1.5B math training script** and local configuration template.
- A tree-versus-linear scoring test for a running teacher server.

The repository includes both source trees: `slime_tree/` for training and `sg_tree/` for SGLang inference. See the [setup guide](docs/reproduction.md) for installation, model and dataset downloads, and training.

## Quick start

Use the **official Slime Docker image** and install the local Slime and SGLang implementations inside the container. Training uses Ray, with **8 GPUs per training node**, and a teacher served by the SGLang implementation in `sg_tree/`.

```bash
git clone https://github.com/zui-jiang/LGR.git
cd LGR
cp .env.example .env
# Edit .env for your model, dataset, teacher, and Megatron paths.

# Preview the training command without contacting services or submitting a job.
bash scripts/train_lgr.sh --dry-run
```

### Install SGLang and Slime

Start the official Slime Docker container as described in the [setup guide](docs/reproduction.md#1-docker-environment). Inside the container, install the two local implementations:

```bash
export LGR_ROOT=/workspace/LGR
python -m pip install -e "$LGR_ROOT/sg_tree/python" --no-deps
(cd "$LGR_ROOT/slime_tree" && python -m pip install -e . --no-deps)
python -c 'import sglang, slime; print("SGLang:", sglang.__file__); print("Slime:", slime.__file__)'
```

The `sglang` import should resolve to `sg_tree/python/sglang`, and the `slime` import to `slime_tree/slime`. Use these local implementations on the corresponding teacher and training hosts.

The [setup guide](docs/reproduction.md#2-models-and-datasets) includes download commands, Polaris field conversion, and student checkpoint conversion.

### Train

Prepare the teacher and Ray services following the [setup guide](docs/reproduction.md), then run the training entry point:

```bash
bash scripts/exp258-distill-1.5B-v3.sh
```

Use `.env` to configure local paths, teacher endpoints, and experiment tracking. Checkpoints are written to `shell/checkpoint/$EXP_NAME/`; use a new `EXP_NAME` to start a separate run.
